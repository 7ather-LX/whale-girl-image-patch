# v1.2.0 · 任意角色自动识别（不用提前添加）

> 适配 **鲸鲸 4.1.2**。安装后请完全退出启动器（托盘右键退出）再打开。

## 这次改了什么

以前要指定角色，得先在管理页手动添加「名称 + Safebooru tag」，
但用户和群友不可能提前知道自己会想找谁。v1.2.0 改成：

```text
看看波奇酱的脚
看看孤独摇滚的波奇酱
看看葬送的芙莉莲
看看某个冷门角色
```

- 从指令里自动提取「角色对象」和「属性」（脚、腿、裤袜、校服…）；
- 未配置的角色，用基础软件已配置的模型自动翻译成 Safebooru 角色 tag；
- 结果缓存 30 天，同一个角色第二次不再调用模型；
- 模型不可用 / 认不出时，退回 B 站搜索该中文名，至少发相关封面；
- 管理页「角色对象」只用于给常用角色固定别名 / tag，**不添加也能用**。

## 例子

`看看波奇酱的脚`：

```text
对象：波奇酱
属性：脚/足
模型解析：gotoh_hitori
查询：gotoh_hitori barefoot 1girl solo
```

找不到足部图时，会依次尝试该角色的普通图，再退到 B 站搜索。

## 内置兜底

东海帝皇、目白麦昆、特别周、无声铃鹿、黄金船、北部玄驹、优秀素质、米浴、
初音未来、雷姆、亚丝娜、02、芙莉莲、阿尼亚、时崎狂三、樱岛麻衣。

这些不走模型，直接有固定 tag；其他角色自动识别。

## 安全

- 仍只请求 Safebooru `rating:safe`，排除泳装 / 内衣 / 裸露 / 未成年等标签；
- 模型只负责「中文名 → 英文角色 tag」，不会生成图片，也不会拿到聊天内容；
- 自动识别可以在管理页关掉。

## 安装

1. 先装鲸鲸 **4.1.2**；
2. 下载 ZIP 解压，双击 `install.cmd`；
3. 完全退出启动器再打开；
4. 左侧「图片」栏 / <http://127.0.0.1:8787/image-patch/>。

## 已知限制

- 自动识别依赖基础软件的模型 Key；没 Key 时只能走 B 站中文搜索。
- 冷门角色或「角色 + 足部」组合图可能很少，会回退到该角色普通图。
