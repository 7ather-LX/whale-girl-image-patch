# v1.0.5 · 多文件启动器维护版

> 适配 **鲸鲸 4.1.2**。安装后请完全退出启动器（托盘右键退出）再打开。

## 变更

- 启动器继续使用**多文件构建**（exe + DLL），Defender 扫描 no threats；
- 左侧 **「补丁 / 图片」** 两栏；
- 安装器识别自定义目录并按 4.1.2 匹配；
- 图片功能不变：来张美图 / 看看脚 / B站图片、24 小时去重、文字提示可关。

## 安装

1. 先装鲸鲸 **4.1.2**；
2. 下载 ZIP 解压，双击 `install.cmd`；
3. 完全退出启动器再打开；
4. 管理页：<http://127.0.0.1:8787/image-patch/>。
