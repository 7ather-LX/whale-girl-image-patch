# v1.2.1 · 修复私聊不发图

> 适配 **鲸鲸 4.1.2**。更新后请完全退出启动器（托盘右键退出）再打开。

## 修复

- **私聊默认关闭**导致私聊里发「看看东海帝皇的脚」没有图：
  - 旧版本 `scope.privates` 默认 `false`，只有群聊生效；
  - v1.2.1 起默认群聊 / 私聊都开；
  - 升级时旧的「私聊关闭」配置会迁移为开启；
  - 仍然可以在管理页手动关掉私聊，或逐个聊天勾选。
- 群聊逻辑不变。

## 说明

这是配置默认值问题，不是搜图逻辑失效。本机更新后，私聊发图前不需要再单独勾选。

## 安装

1. 先装鲸鲸 **4.1.2**；
2. 下载 ZIP 解压，双击 `install.cmd`；
3. 完全退出启动器再打开；
4. 私聊发 `看看东海帝皇的脚` 测试。
