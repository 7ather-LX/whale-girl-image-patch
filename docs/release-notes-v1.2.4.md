# v1.2.4 · 适配鲸鲸 4.1.8

> 适配 **鲸鲸 4.1.8**。兼容性更新，不改变搜索规则。

## 更新

- 基础软件 4.1.8 的运行时钩子仍兼容：
  - `Gateway.handleInbound`
  - `routes.createRouter`
  - `app.createRuntime`
- 启动器换成 4.1.8 三栏版：
  - **补丁 / 图片 / 生理**；
  - 多文件、框架依赖构建，Defender 扫描无威胁。
- 安装器基础版本提示改为 4.1.8。

## 安装

1. 先装鲸鲸 4.1.8；
2. 下载 ZIP 解压，双击 `install.cmd`；
3. 完全退出鲸鲸再打开；
4. 左侧「图片」栏 / `http://127.0.0.1:8787/image-patch/`。

`data/`、`config.json`、角色配置和历史记录不会被覆盖。
