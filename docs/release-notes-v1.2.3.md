# v1.2.3 · 适配鲸鲸 4.1.7.1

> 适配 **鲸鲸 4.1.7.1**。这是兼容性更新，不改变搜索规则。

## 更新

- 基础软件升级到 4.1.7.1 后，图片补丁的运行时钩子仍兼容：
  - `Gateway.handleInbound`
  - `routes.createRouter`
  - `app.createRuntime`
- 启动器换成 4.1.7.1 的三栏版：
  - **补丁 / 图片 / 生理**；
  - 多文件、框架依赖构建，Defender 扫描无威胁。
- 安装器的基础版本提示改为 4.1.7.1。

## 安装

1. 先装鲸鲸 4.1.7.1；
2. 下载 ZIP 解压，双击 `install.cmd`；
3. 完全退出鲸鲸再打开；
4. 左侧「图片」栏 / `http://127.0.0.1:8787/image-patch/`。

## 说明

`data/`、`config.json`、角色配置、历史记录都不会被安装器覆盖。
