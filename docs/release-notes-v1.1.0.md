# v1.1.0 · 指定角色 + 关键词组合

> 适配 **鲸鲸 4.1.2**。安装后请完全退出启动器（托盘右键退出）再打开。

## 新增：指定单一角色

以前只能选「动漫少女」这种大类别，现在可以直接点角色：

```text
看看东海帝皇
看看东海帝皇的脚
来张东海帝皇的黑丝
看看初音未来的校服
```

### 怎么工作

- 角色名 / 别名命中后，强制走 **Safebooru** 角色 tag；
- 角色后面的「属性」会组合成图库 tag：
  - 脚 / 足 → `barefoot`
  - 腿 → `thighhighs` + `legs`
  - 裤袜 / 黑丝 / 白丝 → `thighhighs` / `black_thighhighs` / `white_thighhighs`
  - 校服 / 和服 / 女仆 / 婚纱 / 猫耳 / 眼镜 / 双马尾 / 笑容 / 偶像舞台
- 例：`看看东海帝皇的脚` 实际查询 `tokai_teio barefoot 1girl solo`；
- 结果按分数、分辨率排序，优先大图；仍只请求 `rating:safe` 并排除泳装/内衣/裸露/未成年等标签。

## 内置角色

东海帝皇、目白麦昆、特别周、无声铃鹿、黄金船、北部玄驹、优秀素质、米浴、
初音未来、雷姆、亚丝娜、02、芙莉莲、阿尼亚、时崎狂三、樱岛麻衣。

其他角色可以在管理页「角色对象」里添加：

- 名称：显示名
- 别名：指令里出现就命中
- **Safebooru 角色 tag**：例如 `tokai_teio`
- 启用

## 管理页

- 新增「角色对象」区；
- 「试一张」可以选择角色 + 输入属性（如 `脚`）预览；
- 旧类别、去重、文字开关、聊天范围都不变。

## 安装

1. 先装鲸鲸 **4.1.2**；
2. 下载 ZIP 解压，双击 `install.cmd`；
3. 完全退出启动器再打开；
4. 左侧「图片」栏 / <http://127.0.0.1:8787/image-patch/>。

## 已知限制

- 角色 tag 必须是 Safebooru/Danbooru 的英文 tag；中文名只用于识别，不直接搜索。
- 某些冷门角色 + 足部组合图很少，可能只找到一两张；找不到会回退到该角色普通图。
