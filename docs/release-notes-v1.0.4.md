# v1.0.4 · 多文件启动器 + 鲸鲸 4.1.2

> 适配 **鲸鲸 4.1.2**。安装后请完全退出启动器（托盘右键退出）再打开。

## 修复 / 变更

- 图片补丁启动器改为**多文件构建**（exe + DLL），不再使用被 Defender 误报的单文件自解压版；
- 启动器左侧恢复 **「补丁 / 图片」** 两栏；
- 安装器自动识别 `F:\deep seek girl\WhaleGirl` 等自定义目录，并按 4.1.2 匹配启动器；
- 发布目录已通过 Defender 扫描（no threats）。

## 安装

1. 先装鲸鲸 **4.1.2**；
2. 下载 ZIP 解压，双击 `install.cmd`；
3. 完全退出启动器再打开；左侧出现「图片」栏；
4. 管理页：<http://127.0.0.1:8787/image-patch/>。

## 功能不变

- `@鲸鲸 来张美图` / `看看脚` / `看看B站`；
- 24 小时跨聊天去重；
- 发图前文字提示可关。
